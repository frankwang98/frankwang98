## About me · 关于我

I'm a software engineer interested in robotics, autonomous driving, and developer tools. I enjoy working across the stack—from vehicle-side runtime software and cloud services to desktop applications, automation, and knowledge platforms.

专注于机器人、自动驾驶与工程工具开发，关注真实场景中的可靠性、可维护性和工程落地。

## Current focus · 近期方向

- **ROS2Drive** — building a multi-scenario autonomous driving stack on ROS 2.
- **ROS2Drive Cloud** — developing vehicle management, mission dispatch, monitoring, telemetry, data replay, and remote operation capabilities.
- **Engineering tools** — creating practical C++/Qt, Python, and web tools to improve development workflows.
- **Knowledge sharing** — maintaining technical notes and general-knowledge resources on my personal website.
